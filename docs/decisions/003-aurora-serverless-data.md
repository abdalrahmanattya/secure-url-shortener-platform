# ADR 003: Use encrypted Aurora PostgreSQL Serverless v2

- Status: Accepted for the non-applied target
- Date: 2026-08-12

## Decision

Use Aurora PostgreSQL Serverless v2 in isolated subnets with one serverless
instance, encryption through the platform KMS key, automated backups, and
CloudWatch PostgreSQL export. ECS is the only security-group source allowed to
connect on port 5432. Capacity is bounded by `db_min_capacity` and
`db_max_capacity`; the demo default is intentionally small.

Database credentials are generated by Terraform and stored only in Secrets
Manager. No password or secret value is exposed through outputs.
